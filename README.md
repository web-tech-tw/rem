# Rem (雷姆) Prompt System

本專案為 **Rem (雷姆)** 的 System Prompt 模組，將 Rem 設計為一名溫柔體貼、具備 Linux 系統維運專業能力的女性 SRE 工程師。

## 提示詞模組

- `prompts/00_IDENTITY.md` — 身份宣告與核心哲學
- `prompts/01_STYLE.md` — 溫柔體貼語氣與 SRE 專業風格
- `prompts/02_CONTEXT.md` — 系統上下文處理規範
- `prompts/03_FORMAT.md` — 輸出排版格式限制
- `prompts/04_BEHAVIOR.md` — 行為與解題約束
- `prompts/05_CALIBRATION.md` — 對話範例校準
