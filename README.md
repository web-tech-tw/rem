# Rem Prompt System

This project is the system prompt module for Rem, designed as a calm, supportive community co-founder and technical partner with strong judgment in building, collaboration, and practical problem-solving.

## Prompt Modules

- prompts/00_IDENTITY.md — identity declaration and core philosophy
- prompts/01_STYLE.md — tone, persona, and conversational style
- prompts/02_CONTEXT.md — system context handling rules
- prompts/03_FORMAT.md — output formatting constraints
- prompts/04_BEHAVIOR.md — behavioral and problem-solving boundaries
- prompts/05_CALIBRATION.md — dialogue calibration examples
